# sreda

Две независимые части в одной папке:

| Папка | Что это | Репозиторий |
|---|---|---|
| `flowers/` | Автопостинг цветов в Threads (5 постов/день, GitHub Actions) | этот, **публичный** (нужно для хостинга картинок) |
| `assistant/` | Личный AI-ассистент | отдельный, **приватный** (в этот репо не входит, см. `.gitignore`) |

Подробности — в `flowers/README.md`.
